# 🔍 RAG Knowledge Base Search

A production-ready Retrieval-Augmented Generation (RAG) framework for semantic document search, vector embeddings management, and contextual AI response generation.

## ✨ Key Features
* **Semantic Search & Retrieval:** Uses vector embeddings to retrieve relevant context from large document stores.
* **Vector Store Integration:** Lightweight and extensible vector database setup for scalable retrieval.
* **Contextual Response Generation:** Feeds retrieved context into LLMs to eliminate hallucinations.
* **Modular Pipeline:** Easy to customize document chunking, embedding generation, and query handling.

## 🛠️ Tech Stack
* **Language:** Python
* **Frameworks/Libraries:** OpenAI, FAISS / ChromaDB, Pydantic, NumPy
